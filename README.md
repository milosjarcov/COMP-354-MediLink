# MediLink

Our COMP 354 team repo for the MediLink assignment. MediLink is a made-up appointment platform for small clinics. We run one short release cycle and manage it like a real team.

**Team:** Clinton Noel, Milos Jarcov, Aren Jinbachian, Yoanna Nakhla

## Incidents
Open every incident with the Incident template. It gets a Five Whys within 2 working days and stays open until every follow-up has an owner.

## Support
Each week one person handles all support requests. See the [support rotation](docs/support-rotation.md).
