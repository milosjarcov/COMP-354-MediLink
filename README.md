# MediLink

This is our COMP 354 team repository for the MediLink assignment. MediLink is a made-up Canadian company with an online appointment platform for small medical and dental clinics. Patients search for open appointments, book or cancel them, and get reminders. Clinic staff manage schedules from an admin interface.

We are not building the whole app. We run one short development cycle for the next MediLink release and manage it the way a real team would, with work items, a workflow board, reviews, daily updates, incidents, risks and metrics.
